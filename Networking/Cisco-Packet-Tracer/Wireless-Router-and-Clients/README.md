Cisco Packet Tracer — Wireless Router and Clients:

Overview:
A hands-on Cisco Packet Tracer activity focused on configuring a home network with wired and wireless clients.
The activity involved connecting network devices, configuring a home wireless router, setting up DHCP and wireless security, connecting a wireless client, and testing network connectivity.

Skills Practiced:
* Network device connectivity
* Coaxial and Ethernet cabling
* Wireless router configuration
* DHCP configuration
* IP addressing
* Wireless LAN configuration
* SSID configuration
* WPA2 Personal security
* Network connectivity testing
* Basic troubleshooting

Network Configuration

The activity included:
* Cable splitter
* Cable modem
* Home wireless router
* Office PC
* Bedroom PC
* Laptop
* TV

The wireless network was configured with the SSID:
`MyHome`
Wireless security was configured using:
`WPA2 Personal`

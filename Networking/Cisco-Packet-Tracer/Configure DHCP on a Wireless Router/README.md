Cisco Packet Tracer — Configure DHCP on a Wireless Router
Overview:

A hands-on Cisco Packet Tracer activity focused on configuring DHCP on a wireless router and automatically assigning IP addresses to multiple clients.

The activity involved connecting three PCs to a wireless router, modifying the router's IP address, changing the DHCP address range, configuring the clients to obtain IP addresses automatically, and verifying network connectivity.
